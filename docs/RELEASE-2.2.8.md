# MapAdKiller / MapClean 2.2.8（versionCode 2280）

发布日期：2026-10-28。版本码：2280。基线 2.2.7（versionCode 2270）。

本轮全部是修 bug 和可用性，没有新开关。

## 百度地图

- **路线页「开始导航」消失**：收壳逻辑会把整条底栏一起 GONE 掉（刷新重建时兄弟还没测量，被误判成「只剩我一个」），
  而 View 实例会被宿主复用，再也回不来。现在底栏（类名含 `BottomBar` / `PageBottom`）一律不参与收壳。
- **面板「只读 · 无法写入配置」误报**：百度/腾讯分支只认框架服务，服务没绑上就判死。
  现在会先做一次真实写入探测，能写就显示可写（与高德一致）。
- **内置版日志抓取不可用**：百度内置版把 `mapadkiller` 整包裁掉时把 `CaptureLog` 换成了空实现，
  面板里的「日志抓取」点了没反应。改为按文件保留真实 `H` / `CaptureLog`，用户能自己导出日志反馈。

## 高德地图

- **自动巡航触发值可调**：新增「自动巡航」设置页，两个滑块 —— 触发速度下限（2–30 km/h）、
  触发持续时间（2–30 秒）。地图内悬浮球面板和模块 App 两处都能调，读写同一组 key。
- **走路也能触发**：以前单步位移要 ≥ 8 km/h 才计入窗口、窗口总位移要 60 米，走路永远攒不满。
  现在三个门槛跟着触发速度走（2 km/h 档 = 1.6 km/h / 15 米 / 11 米），精度上限在低速档放宽到 120 米。
- **抓取完成提示只弹一次**：以前标记不清，抓完很久了每次打开还弹。

## 模块 App

- 应用列表：**已安装的排前面**，未安装的沉底。
- 未安装的行**不再显示「推荐 x」** —— 那是模块验证过的固定版本号，跟用户手机装什么无关。
- 百度 / 高德 / 腾讯三行都显示**自己的原生图标**（内嵌原图，未安装也能显示）。
- 滑块写入失败会**退回原值并提示**「未连接地图：先打开高德，再回来调」，不再静默丢弃。

## 构建

- `module.prop` 的 `version` / `versionCode` 改为构建时从 `Version.java` 生成。
  此前是手写的，2.2.5 起一直停在旧值，导致 LSPosed 模块仓库页面显示的版本号长期落后。
